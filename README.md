# Ecosia to Google

A small Chrome extension that keeps Ecosia as your default search engine but adds a one-click escape to Google when you need it.

## What it does

On `ecosia.org` pages, it:

- Adds a "Go to Google" link to the search navigation
- Rewrites the Images tab to open Google Images directly

The toolbar popup just shows whether the extension is active on the current tab.

## Install (unpacked)

1. Open `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
