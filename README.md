# Ecosia to Google

A small Chrome extension that keeps Ecosia as your default search engine but adds a one-click escape to Google when you need it.

## What it does

On `ecosia.org` pages, it:

- Adds a "Go to Google" link to the search navigation
- Rewrites the Images tab to open Google Images directly

On `google.com` pages, it rewrites the links in the page's list items to point back to Ecosia with the same query.

The toolbar popup shows whether the extension is active on the current tab. On a Google tab it offers a "Back to Ecosia" button that reopens your query on Ecosia, and on any other tab it offers a shortcut to ecosia.org.

## Install (unpacked)

1. Open `chrome://extensions`
2. Enable "Developer mode"
3. Click "Load unpacked" and select this folder
